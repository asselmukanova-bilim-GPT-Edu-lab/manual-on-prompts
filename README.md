# Методическое руководство по созданию промтов

Практический сайт Bilim UpSkill для педагогов: конструктор шести типов промптов, шаблоны, инфографика, безопасность, проверка результата и справочные НПА Республики Казахстан.

`index.html` — автономная сборка сайта: все стили, код и оригинальные фирменные изображения включены в страницу. Её можно открыть локально или разместить через GitHub Pages из корня ветки `main`. Внешние библиотеки, API-ключи и установка зависимостей не нужны.

`bilim-upskill-prompt-guide.zip` — полный редактируемый проект с централизованными данными, исходными компонентами, изображениями, сборкой, тестами и документацией. Для разработки распакуйте архив и следуйте README внутри проекта.

Сборка из исходников: `node scripts/build.mjs`. Проверка: `node --test tests/prompt.test.cjs`.

Сайт не отправляет данные формы на сервер и не вызывает модель ИИ. Он составляет текст запроса; результаты ИИ проверяет педагог. Нормативные сведения носят справочный характер: сверяйте актуальную редакцию официального источника.

Содержание адаптировано по предоставленному «Методическому руководству по созданию промтов», Bilim Group, 2026. Логотипы и фирменные элементы извлечены из предоставленного PDF; права сохраняются за правообладателями.
